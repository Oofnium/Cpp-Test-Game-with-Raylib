# story.txt - the whole script lives here. No recompiling needed:
# save this file, go to the main menu and press R, then pick New Game.
#
# FORMAT
#   SCENE <route> <chapter> <npc> <map> <x> <y>   [AUTO]  [REQ:condition]
#                                   starts a scene. The character stands at tile (x, y) of that map
#                                   (see world.txt) until you finish the scene. Walk up and press E.
#                                   route -1 = original story, 0 = Naomi's Route, 1 = Stella's Route
#                                   AUTO: no E needed. The scene starts by itself when you walk up to the spot.
#                                   The npc can be Narrator for AUTO scenes: nobody stands there, the spot
#                                   is just marked on the floor (a tile trigger).
#                                   With REQ:condition at the end, the scene only appears while that is true.
#   Name: text                      one line of dialogue
#   Name (expression): text         same, and the portrait switches to that expression (like annoyed)
#   ? answer | anonPoints | partnerPoints | reply  [| FLAG: name]  [| REQ: condition]
#                                   an answer to the line right above it (use 2 or 3 of them).
#                                   FLAG: switches a story flag on when this answer is picked.
#                                   REQ: keeps the answer locked until the condition is true.
#   FLAG: name                      on its own line inside a scene: switches a story flag on when the scene ends.
#                                   Use it to chain scenes in order: scene A ends with FLAG: a_done, and scene B
#                                   starts with REQ:flag:a_done, so B only appears after A.
#   IF condition ... ENDIF          lines between them only play while the condition is true (no IF inside an IF).
#                                   Use it for story branches: an answer sets a flag, the lines for that branch sit in an IF.
#   REQ and IF conditions can be joined with &:   REQ:flag:a&!flag:b   or   IF flag:a & anon>=2
#   An answer with an empty reply (? text | 0 | 0 | ) just carries on with the story; add | FLAG: name to remember the choice.
#   END                             ends the scene
#
# A line spoken by Narrator is shown with no name label (it's Anon's narration / thoughts).
# A speaker called ??? is a voice you can't place yet. Only plain letters, numbers and punctuation: no curly quotes.
#
# CONDITIONS (no spaces inside):  flag:name    !flag:name    anon>=2    partner<1
#                                 (compare with >=  >  <=  <  ==)
#
# Lines starting with # are ignored. Don't use the | symbol inside the text.
# Rules the game checks for you:
#   - every chapter (1, 2, 3...) needs at least one scene WITHOUT a REQ, so it can always be finished
#   - every question needs at least one answer WITHOUT a REQ
#   - a flag used in a REQ has to be set by some answer or scene (this catches typos)
