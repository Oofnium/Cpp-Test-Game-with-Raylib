# world.txt - the maps and the doors between them. No recompiling needed:
# save this file, go to the main menu and press R.
#
# FORMAT
#   MAP <name>                      starts a map. Then one line per row of tiles. Then END.
#                                   (use _ instead of spaces in names, like school_entrance)
#   WARP <map> <x> <y> <to-map> <x> <y>
#                                   a door: stepping on tile (x, y) moves you to the other map's tile
#                                   Tile numbers count from 0 at the top-left. The arrival tile must
#                                   NOT be a door itself, so put it one step in front of the return door.
#   START <map> <x> <y>             where a new game begins
#
# TILES   #  wall      .  floor      g  grass      r  road
#         T  tree      x  furniture / obstacle
# Walls, trees and furniture block you. Every row in a map must be the same length.
# (Comments are only allowed OUTSIDE a map, because # is also the wall tile.)
